# 大商所持仓爬虫 - 使用说明

## 📁 文件位置（在下载文件夹中）

1. **大商所持仓爬虫.py** - 推荐使用！最简单的版本
2. **dce_crawler.py** - 完整功能版本
3. **README_DCE_CRAWLER.md** - 详细使用说明

## 🚀 快速使用

### 方法一：直接运行（推荐）
```bash
cd /home/liyuexuan/下载
python 大商所持仓爬虫.py
```

### 方法二：使用完整版本
```bash
cd /home/liyuexuan/下载
python dce_crawler.py --variety "铁矿石"
```

## 📊 运行后生成的文件

运行程序后，会在当前目录生成 `dce_data` 文件夹，包含：
- **铁矿石持仓数据.json** - JSON格式数据
- **铁矿石持仓数据.xlsx** - Excel格式数据
- **页面截图.png** - 页面截图

## 💡 提示

- 第一次运行需要下载Chrome驱动，请耐心等待
- 程序会自动打开浏览器窗口，不要关闭
- 数据会自动保存到当前目录的 `dce_data` 文件夹

## 🔄 支持的品种

铁矿石、豆粕、焦炭、豆油、玉米、聚乙烯等多个期货品种
